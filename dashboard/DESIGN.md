| 项 | 内容 |

## 1. 设计依据

| 项 | 内容 |
| --- | --- |
| 产品 | WaiShe，跨品牌外设管理。Dashboard 是从托盘或浏览器打开的轻量配置工具 |
| 使用者 | 同时使用多个品牌外设的 PC 用户，需要直观查看状态并偶尔调整核心参数 |
| 首要任务 | 一眼识别每台外设的类别、连接状态、关键参数与电量 |
| 次要任务 | 调整 DPI、回报率等设备功能；管理协议驱动与客户端设置 |

视觉语汇取自现代哑光外设硬件：哑光金属/塑料表面层级（画布、卡片、次级面板）、统一风格的线框外设图标与语义指示灯。

## 2. 原则

1. **以设备为中心，而不是数据表格。** 首页以设备图标、名称、类型与核心实时状态为视觉重心；固件版本、VID:PID、内部型号标识等技术信息退居折叠区。
2. **明确的信息优先级。**
   - 一级：设备名称、核心连接状态、当前正在配置的功能。
   - 二级：电量、充电状态、DPI、回报率、麦克风状态。
   - 三级：固件版本、驱动版本、设备标识。
   - 四级：数据读取时间、持久性说明、协议验证提示。
3. **语义色只表示状态，且不单独依赖颜色。** 正常（绿）、注意/待应用/未审核（琥珀）、故障/严重低电/危险操作（红）、离线/历史值（灰），始终配合文字标签与图标出现。
4. **不将缓存数据伪装成实时值。** 顶部状态栏明确表示 `Bridge 已连接`（本地服务状态）；每台设备与每个功能各自显示真实读取时间与历史值/不可用状态。
5. **不做乐观更新，写入结果明确。** 区分当前设备已确认值、未提交的草稿修改、正在写入、写入已回读确认（`applied`）、仅命令发送（`accepted`）和写入失败（`rejected` / `failed`）。

## 3. 色彩与主题

支持 **跟随系统**（默认）、**深色模式** 与 **浅色模式** 三种外观（`<html data-theme="dark|light">`）。

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--shell` | `#EEEFF2` | `#16181B` | 页面画布底色 |
| `--plate` | `#FFFFFF` | `#202328` | 设备卡片、配置卡片、设置卡片表面 |
| `--surface-raised` | `#F5F6F8` | `#282C33` | 图标容器、按键、表格表头、次级控件表面 |
| `--surface-subtle` | `#E6E8EC` | `#1B1E23` | 技术信息折叠区、离线设备底色 |
| `--graphite` | `#1C1F23` | `#ECEEEF` | 一级文字、主按钮底色、焦点环 |
| `--muted` | `#525A65` | `#969DA6` | 二级/三级信息、说明文字 |
| `--subtle` | `#616A75` | `#828A95` | 四级信息（读取时间、辅助提示） |
| `--groove` | `#D5D9E0` | `#31363F` | 卡片边框、分隔线、滑轨 |
| `--led-on` | `#1F9D55` | `#3DD37A` | 已连接、电量正常、写入确认成功 |
| `--led-low` | `#B7791F` | `#F2B53A` | 低电量、待应用修改、未经审核提示 |

## 4. 字体与排版

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| 数字与硬件标识 | Barlow Condensed（600、500），内嵌 woff2 | 电量、DPI、Hz、版本号、VID:PID、WaiShe 字标，等宽数字 |
| 正文与中文 | `"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif` | 系统字体，不发起外部网络请求 |

- 主要页面最大宽度 `960 px`；驱动管理与设置页面使用居中限宽 `820 px`。
- 响应式支持至 `320 px` 窄屏与 `400 × 640` 原生紧凑面板（`#/panel`）。

## 5. 页面结构

- **设备列表页**：顶部栏含页面标题、数量徽章、“显示已隐藏”筛选开关与“全部 HID 设备”诊断入口；每台设备卡片分为识别区（类型图标 + 名称 + 实时参数标签）、状态区（连接状态 + 传输方式 + 读取时间）与电量/入口区。
- **设备详情页**：顶部设备概览卡突出名称、类别图标、连接状态与电量；“设备管理”抽屉按需展开修改别名与隐藏；主体区域按设备实际能力动态排版配置卡片（DPI 卡片全宽，滑块+精确数字+常用档位+可展开 X/Y 独立设置；只读状态如耳机麦克风采用独立图标状态卡）；技术信息收入底部可折叠区域。
- **驱动管理页**：顶部提供显眼的安装本地驱动入口；驱动卡片默认展示名称、版本、分层状态徽章（运行状态、来源、验证状态）、支持型号与当前关联设备；许可证/源码等细节与卸载操作收入展开区，卸载确认弹窗列出受影响设备。
- **设置页**：分为常规（语言、开机自启、主题）、设备监控（读取间隔、低电量提醒及联动子项）、系统托盘（带迷你托盘图标预览的模式选择卡）、更新与网络、开发者与关于。

## 6. 动效与无障碍

- 默认克制无冗余装饰动画；写入完成时仅保留 150 ms 读数过渡，尊重 `prefers-reduced-motion`。
- 全键盘可操作，焦点环为 2 px 外壳色间隔加 2 px 石墨色外框。
- 满足 WCAG AA 文字对比度要求。
