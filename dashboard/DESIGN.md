| 项 | 内容 |
| --- | --- |
| 日期 | 2026-11-14 |

## 1. 设计依据

| 项 | 内容 |
| --- | --- |
| 产品 | WaiShe，跨品牌外设管理。Dashboard 是从托盘偶尔打开的工具页 |
| 使用者 | 同时使用多个品牌鼠标、耳机的 PC 用户，熟悉 DPI、回报率等术语 |
| 首要任务 | 一眼看清每个设备的电量与是否在线 |
| 次要任务 | 偶尔调整 DPI、回报率；管理驱动与设置 |

视觉语汇取自外设本身：哑光塑料外壳、状态指示灯、底部的型号标签、推子式的控制。

## 2. 原则

1. **颜色只表示状态。** 界面本身只有外壳色与石墨色两种中性色。彩色只出现在指示灯语汇里：绿表示在线或健康，琥珀表示电量低，红表示严重或故障，灰表示离线或历史值。按钮、选中、焦点都用石墨色，不另设品牌强调色。
2. **数字就是界面。** 电量、DPI、回报率用大号窄体数字呈现，等宽数字，左对齐成列。标签小而安静。
3. **清单，不是卡片。** 设备是一张设备清单里的行，用分隔线区分，不用阴影卡片。控件分组靠间距与小标题，不靠边框盒子。
4. **历史值像熄灭的指示灯。** 不是实时的值一律用熄灯灰与“上次读取 …”表示，绝不显示成正常颜色。
5. **只在一个地方大胆**：设备清单的电量数字列。其余保持克制。

## 3. 色彩

| 名称 | 浅色（哑光白外壳） | 深色（哑光黑外壳） | 用途 |
| --- | --- | --- | --- |
| shell | `#E6E7E8` | `#1E1F21` | 页面背景 |
| plate | `#F3F3F2` | `#27292C` | 输入框、按键、提示条等需要与背景区分的表面 |
| graphite | `#24272B` | `#E7E7E4` | 正文、标题、主要按钮、选中态、焦点环 |
| muted | `#5E636A` | `#9A9EA4` | 次要文字、标签 |
| groove | `#C4C7CB` | `#3A3D41` | 分隔线、输入框边框、滑轨 |
| led-on | `#23A55A` | `#3DD37A` | 在线、电量正常、写入成功 |
| led-low | `#B97F00` | `#F2B53A` | 电量低于提醒阈值、警告 |
| led-fault | `#C93A2E` | `#F0675B` | 电量严重不足（≤ 10%）、故障、错误 |
| led-off | `#8F959B` | `#6F747A` | 离线、历史值、未知 |

浅色下 led-low 与 led-fault 用于文字时取上表值以保证对比度；作为圆点或条形时可用更亮的同色相。

## 4. 字体

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| 数字与英文标识 | Barlow Condensed（600、500），内嵌 woff2，仅含拉丁字母、数字与常用符号 | 电量、DPI、Hz、型号、VID:PID、WaiShe 字标。一律等宽数字 |
| 正文与中文 | 系统字体：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif` | 不内嵌中文字体 |

字号（以 15 px 为基准，比例约 1.25）：

| 级别 | 字号 | 用途 |
| --- | --- | --- |
| xs | 12 px | 辅助说明 |
| sm | 13.5 px | 标签、次要信息 |
| base | 15 px | 正文 |
| md | 18.75 px | 设备名称、小节标题 |
| lg | 23.4 px | 页面标题 |
| num-m | 46 px（窄体） | 设备清单中的电量 |
| num-l | 57 px（窄体） | 设备详情中的电量与 DPI 读数 |

正文行宽不超过 80 字符。不使用全大写标签，不给标题中的单个词加粗或换色。

- 电量数字列宽固定，所有行的数字左边缘对齐。电量 ≤ 提醒阈值为琥珀色，≤ 10% 为红色，历史值为熄灯灰。
- 整行是一个链接，进入设备详情。

```text

                              [125] [500] [1000 Hz]
```

- 左栏像设备底部的型号标签：定义列表，标签 muted，值 graphite。
- DPI：大号读数；滑条像推子，常用值作为刻度标在滑轨下方，可直接点选；当前值在刻度上以石墨色标记。
- 回报率等枚举值用按键式分段按钮，选中为石墨底、外壳色字。
- 写入期间读数旁显示“正在写入”，结果在读数下方用一行文字说明，成功为 led-on 色，失败为 led-fault 色。

设置面板（约 400 × 640 的原生窗口）：同样的设备清单行，数字缩小为 36 px；下方是设置项，不出现导航栏。

## 6. 文案

- 从使用者角度命名：“设备”“驱动”“设置”，不出现“能力”“端点”等内部术语。
- 按钮写明结果：“应用 DPI”“安装驱动”“卸载驱动”。成功提示与按钮同词：“已应用”“已安装”“已卸载”。
- 出错时说明发生了什么、怎么办，不道歉、不含糊。例如“无法连接 WaiShe。确认它在系统托盘中运行，然后重试。”
- 空状态给出下一步：“还没有设备。连接设备后，在“驱动”中安装对应的驱动。”
- 元信息不用中点拼接，分字段或分行显示。

## 7. 动效

- 默认没有进场动画、没有悬停动画。
- 唯一的动效：写入完成时读数数字的一次短暂过渡（150 ms），表示值已经更新。`prefers-reduced-motion` 时取消。

## 8. 质量底线

- 键盘可完成全部操作，焦点环为 2 px 石墨色加 2 px 外壳色间隔。
- 文字对比度满足 WCAG AA。
- 320 px 宽仍可用。
- 不发起任何网络请求，字体随构建内嵌。

## 9. 对照常见默认风格的自查

| 常见默认 | 本设计 |
| --- | --- |
| 米色背景加衬线标题加陶土色强调 | 冷灰外壳色，窄体无衬线数字，无强调色 |
| 近黑背景加单一荧光强调色 | 深色为 `#1E1F21` 哑光黑，彩色只表示状态且面积小 |
| 报纸式细线与密排多栏 | 单列清单，分隔线只用于区分设备行 |
| 统一圆角卡片加灰色阴影 | 去掉卡片与阴影；表面区分靠外壳色与 plate 色 |
| 全大写小标题、中点拼接元信息、等宽字体小标签、按钮后加箭头 | 全部不用 |
| 大数字加小标签的主视觉 | 大号电量数字是本产品的首要信息，作为可比较的数字列使用，不配渐变与附属统计 |
