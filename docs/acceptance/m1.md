## 3. 性能

安装版（发布构建）在后台空闲运行，两台设备在线，Dashboard 与设置面板均关闭，采样 300 秒：

| 指标 | 实测 | 要求 |
| --- | --- | --- |
| 平均 CPU | 0.047% 单核 | PERF-01：< 0.1% |
| 私有内存 | 20.9–21.0 MiB，采样期内无增长 | PERF-01：< 40 MB |
| 安装包 | 3.82 MiB | PERF-03：< 20 MB |
| 冷启动到首个电量读数 | < 1 s | PERF-04：< 5 s |
| DPI 写入到返回结果 | 0.21 s | PERF-05：< 0.5 s |

设置面板打开时，WebView2 进程另占约 170 MB 私有内存，关闭即释放（ADR-0005）。

## 5. 验收中发现并修正的问题

| 问题 | 修正 |
| --- | --- |
| 耳机播放语音提示时查询超时，被当成断开，其他能力也被标为未连接 | 超时、忙、I/O 错误视为瞬时错误：保持连接状态，5 秒后重试 |
| Dashboard 打开后，已排好的 5 分钟轮询不会提前 | 出现观察者时立即提前已排好的轮询 |
| 无观察者时鼠标关机最长 5 分钟才被发现 | 连接状态至少每 60 秒检查一次（一次约 100 ms 的查询，已实测不会唤醒鼠标） |
| 托盘图标两位数宽度超出 32 像素（调试构建溢出） | 改为数字间固定 1 像素间距，并加测试覆盖 0–100 |
| DPI 只能输入数字，不符合使用习惯 | Dashboard 改为非线性滑条 + 常用预设，X/Y 输入收入“高级” |
