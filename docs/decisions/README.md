## 状态

- **提案**：已有倾向，等待验证或评审。
- **已接受**：现行决定。
- **已替代**：被后续决策取代，文件保留并指向新编号。

## 新增决策

1. 复制最近一个文件的结构：背景、决定、备选方案、后果。
2. 编号顺延，文件名用英文短横线形式。
3. 在上表登记。
4. 已接受的决策不改写结论；要改变就新增一条并把旧的标为已替代。
